# 实习与求职定位初评

版本 v1.2.0 · 作者 Betty（小鹿） · MIT License

帮助在校生找实习、准备校招，以及已毕业仍在寻找第一份全职工作的应届生做阶段性定位初评。支持学生自查和导师首访准备。

## 安装

本包面向支持本地 Skill 的 Codex。解压后保留整个 resume-intake-review 文件夹，交给 Codex 并说“请把这个文件夹里的 Skill 安装为我的个人 Skill”。按安装结果提示在新对话中调用。

其他支持 Skill 的工具，请按照该工具的安装方式使用本文件夹。目前未逐一验证其他工具的兼容性。

## 学生入口

附上已去除姓名、联系方式、证件号和学校学号等身份信息的简历、简要经历，有目标岗位原文也可以一起提供，然后输入：

> 用 $resume-intake-review 帮我做实习与求职定位初评。我是学生，请先根据材料给初步反馈，再逐次问关键事实。

AI 先展示已有积累、可探索方向及不确定之处，再问项目做了什么、本人负责什么、有什么产出。记不清时，回忆具体细节，同时寻找作业、作品或分工记录。本人能确认但没有佐证的部分按自述记录，尚未确认的部分留待补充。

你可以选择先拿阶段性初评去行动，也可以继续对照真实岗位。对照时提供岗位原文或官方链接；能否在线查找取决于使用工具的联网能力。阶段性结果包括诉求与积累、方向及依据、待补事实与材料、下一步。日后可以带材料回来继续。

[学生入口示例](references/学生入口示例.md)

## 导师入口

提供去除学生身份信息的简历、转介绍备注和已核实信息，选择一句启动语。

> 用 $resume-intake-review，为这位新转介的学生直接准备首访初评。我尚未与本人详细访谈。

> 用 $resume-intake-review，围绕这次咨询的重点做初评：我想判断这位学生的现有积累可以支持哪些第一段实习方向。

结果包括目前能看出的线索、值得探索的具体职责、待核实事项，以及按重要程度排列的首访问题。学生经历的未知细节留给本人回答。导师可按本次需要选择用法。

[导师首访示例](references/首访前初评示例.md)

## 版本状态与使用反馈

双入口流程已加入，文件结构校验通过。新版双入口的实际对话试用与真实用户反馈仍待补充。初评根据现有材料形成，可随着经历核实和岗位对照更新，不预测网申通过率或承诺录用。

两个示例均为明确标注的虚构教学材料。提交公开反馈时使用匿名概述，可说明使用入口、原本期待、实际遇到的问题和希望怎样调整。不要在公开问题区上传原始学生简历。
